## [1.0.1] - 2025-10-21

### Agregado
- **Backend (Spring Boot 3.5.5)**
  - Configuración inicial del proyecto Spring Boot
  - Integración con Spring Security para autenticación
  - Configuración de Spring Data JPA para persistencia
  - Conexión a base de datos MySQL
  - Dependencias de desarrollo con Lombok
  - Configuración de DevTools para desarrollo

- **Frontend (React 19.1.1)**
  - Configuración inicial del proyecto React con Vite
  - Integración de Material-UI (MUI) para componentes
  - Configuración de Tailwind CSS para estilos
  - Implementación de React Router para navegación
  - Configuración de ESLint para calidad de código
  - Iconos con Lucide React y Boxicons

- **Proyecto General**
  - Estructura de proyecto full-stack
  - Configuración de Git con .gitignore
  - Documentación inicial (README.md)
  - Licencia MIT
  - Archivos de contribución (CONTRIBUTING.md)

### Tecnologías Utilizadas
- **Backend**: Java 17, Spring Boot 3.5.5, Spring Security, Spring Data JPA, MySQL
- **Frontend**: React 19.1.1, Vite, Material-UI, Tailwind CSS, React Router
- **Herramientas**: Maven, npm, ESLint, Lombok
